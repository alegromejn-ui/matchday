# Матчдей — прогнози на футбольні матчі

Мобільний веб-застосунок. Працює без сервера: усе виконується у браузері, ключі API вводяться в самому застосунку й зберігаються тільки на вашому телефоні.

## Файли
- `index.html` — інтерфейс
- `app.js` — підключення API та модель прогнозу
- `manifest.webmanifest`, `icon.svg` — щоб додати на головний екран як застосунок

## Запуск через GitHub Pages
1. На github.com натисніть **New repository**, назвіть його `matchday`, оберіть **Public**.
2. Натисніть **uploading an existing file** і перетягніть усі файли з цієї папки. Натисніть **Commit changes**.
3. Відкрийте **Settings → Pages**. У розділі **Build and deployment** оберіть **Deploy from a branch**, гілку **main**, папку **/ (root)**, натисніть **Save**.
4. Через 1–2 хвилини сайт буде за адресою `https://ВАШ-НІКНЕЙМ.github.io/matchday/`.
5. Відкрийте посилання на телефоні, натисніть **Ключі API**, вставте ключі й натисніть **Зберегти й оновити**.
6. Щоб мати іконку застосунку: iPhone — «Поділитися → На початковий екран», Android — меню браузера → «Встановити застосунок».

## Де взяти ключі
| Сервіс | Для чого | Безкоштовно |
|---|---|---|
| [the-odds-api.com](https://the-odds-api.com) | список матчів і коефіцієнти (основа прогнозу). **Обов’язковий** | 500 кредитів на місяць. Одне оновлення коштує приблизно 1 кредит на кожен увімкнений турнір |
| [football-data.org](https://www.football-data.org/client/register) | таблиці ліг, голи за/проти → оцінка сили команд | базовий план з обмеженим набором ліг (Ліга Європи не входить) |
| [api-football.com](https://dashboard.api-football.com/register) | власний прогноз сервісу та список травмованих | ліміт запитів на день; у безкоштовному плані можуть бути обмеження за сезонами |

Без другого й третього ключів застосунок працює, але з меншою кількістю джерел.

## Як рахується прогноз
1. Коефіцієнти букмекерів перетворюються на ймовірності (без маржі) й усереднюються.
2. За таблицею ліги оцінюється сила атаки й оборони команд, з цього рахується друга оцінка.
3. API-Football дає третю оцінку й список травмованих.
4. Оцінки поєднуються з вагами (приблизно 60% / 25% / 20%, для команд з різних ліг вага статистики менша).
5. Модель Пуассона перетворює підсумок на очікувані голи, найімовірніший рахунок, тотал і «обидві заб’ють».

## Важливо
- Ліміти: щоб не вичерпати кредити, не оновлюйте дані частіше, ніж потрібно. Коефіцієнти кешуються на 3 години, статистика на 12, аналіз матчу API-Football на 6.
- Безпека: не вставляйте ключі в код і не публікуйте їх у репозиторії.
- Якщо сервіс забороняє запити з браузера (помилка CORS), застосунок покаже це над списком матчів і продовжить працювати з рештою джерел.
- Це аналітика, а не гарантія: навіть найкращі моделі помиляються в половині матчів.
