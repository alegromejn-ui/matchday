# Матчдей — прогнози на футбольні матчі

Мобільний веб-застосунок без сервера. Ключі API вводяться в самому застосунку й зберігаються лише у вашому браузері.

## Файли
`index.html` (інтерфейс), `app.js` (дані та модель), `manifest.webmanifest` і `icon.svg` (іконка застосунку).

## Запуск через GitHub Pages
1. На github.com: **New repository** → назва `matchday` → **Public**.
2. **uploading an existing file** → перетягніть усі файли з папки → **Commit changes**.
3. **Settings → Pages → Deploy from a branch → main → / (root) → Save**.
4. Через 1–2 хвилини сайт відкриється за адресою `https://ВАШ-НІКНЕЙМ.github.io/matchday/`.
5. На телефоні: iPhone — «Поділитися → На початковий екран», Android — меню браузера → «Встановити застосунок».
6. Після оновлення файлів у репозиторії відкрийте сайт і потягніть сторінку вниз або очистіть дані сайту, щоб підтягнулася нова версія.

## Джерела даних
| Джерело | Ключ | Що дає |
|---|---|---|
| ESPN (неофіційний відкритий API) | не потрібен | розклад усіх матчів на 10 днів, таблиці ліг, логотипи команд і турнірів |
| [the-odds-api.com](https://the-odds-api.com) | безкоштовний, необов’язковий | коефіцієнти букмекерів: найточніша складова прогнозу |
| [api-football.com](https://dashboard.api-football.com/register) | безкоштовний, необов’язковий | прогноз сервісу й травмовані гравці |

Турніри: Ліга чемпіонів, Ліга Європи, АПЛ, Ла Ліга, Серія A, Ліга 1, Бундесліга.

## Як рахується прогноз
Ймовірності з коефіцієнтів (≈60%), статистика ліг ESPN (≈25%, для команд з різних ліг менше) і API-Football (≈20%) поєднуються, а модель Пуассона перетворює їх на очікувані голи, рахунок, тотал і «обидві заб’ють». Матчі без коефіцієнтів позначені «лише статистика».

## Можливості
Пошук команди, сортування (час, впевненість, голи), ★ обрані матчі, карта рахунків, симуляція матчу, повзунки складів, кнопка «Поділитися».

## Важливо
- ESPN API не має офіційної документації й може змінитися. Якщо логотипів чи таблиць немає, застосунок покаже помилку й працюватиме з рештою даних.
- Кредити Odds API: одне оновлення коштує приблизно по одному на кожен увімкнений турнір. Дані кешуються (коефіцієнти 3 години, ESPN 6, API-Football 6).
- Це аналітика, а не гарантія результату.
