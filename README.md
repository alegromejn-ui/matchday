# Матчдей — прогнози на футбольні матчі

Мобільний веб-застосунок без сервера. Ключі API вводяться в самому застосунку й зберігаються лише у вашому браузері.

## Файли
`index.html` (інтерфейс), `app.js` (дані та модель), `manifest.webmanifest` і `icon.svg` (іконка застосунку).

## Запуск через GitHub Pages
1. На github.com: **New repository** → назва `matchday` → **Public**.
2. **uploading an existing file** → перетягніть усі файли з папки → **Commit changes**.
3. **Settings → Pages → Deploy from a branch → main → / (root) → Save**.
4. Через 1–2 хвилини сайт відкриється за адресою `https://ВАШ-НІКНЕЙМ.github.io/matchday/`.
5. На телефоні: iPhone — «Поділитися → На початковий екран», Android — меню браузера → «Встановити застосунок».
6. Після оновлення файлів у репозиторії відкрийте сайт і потягніть сторінку вниз або очистіть дані сайту, щоб підтягнулася нова версія.

## Джерела даних
| Джерело | Ключ | Що дає |
|---|---|---|
| ESPN (неофіційний відкритий API) | не потрібен | розклад усіх матчів на 10 днів, таблиці ліг, логотипи команд і турнірів |
| [the-odds-api.com](https://the-odds-api.com) | безкоштовний, необов’язковий | коефіцієнти букмекерів: найточніша складова прогнозу |
| [api-football.com](https://dashboard.api-football.com/register) | безкоштовний, необов’язковий | прогноз сервісу й травмовані гравці |

Турніри: Ліга чемпіонів, Ліга Європи, АПЛ, Ла Ліга, Серія A, Ліга 1, Бундесліга.

## Як рахується прогноз
Ймовірності чотирьох джерел поєднуються зваженим середнім: коефіцієнти (базова вага 0,60), статистика й форма ESPN (0,25; для матчів між різними лігами ×0,4), API-Football (0,20) і рейтинг Ело (0,12; для різних ліг ×2,5). Модель Пуассона з поправкою Діксона-Коулса (ρ = −0,10) перетворює підсумок на очікувані голи, рахунок, тотал і «обидві заб’ють». Матчі без коефіцієнтів позначені «лише статистика».

- **Перевага господарів** рахується окремо для кожного турніру за результатами останніх 8 тижнів, зі стягненням до 1,10 / 0,92.
- **Давність**: форма береться з усіх матчів за 8 тижнів, вага матчу зменшується вдвічі кожні 3 тижні, частка форми в статистичній складовій 35%. Сезонні таблиці ESPN дають лише загальні суми, тому сезон залишається базою.
- **Ело** рахується в застосунку за матчами ESPN: старт від різниці м’ячів сезону й невеликої поправки за силу ліги (АПЛ +50, Ла Ліга +35, Серія A і Бундесліга +20, команди лише єврокубків −70), далі оновлення за результатами. Поправки за ліги — експертна оцінка, не виміряне значення.
- **Калібрування ваг**: «Ще → Калібрування ваг». З’являється після 100 завершених матчів, для яких збережено складові прогнозу (записуються лише в нових прогнозах). Підбір мінімізує лог-втрату на вашій історії, результат стягується наполовину до стандартних ваг, щоб не перепідганяти, і застосовується, лише якщо покращення помітне.

## Можливості
Пошук команди, сортування (час, впевненість, голи), ★ обрані матчі, карта рахунків, симуляція матчу, повзунки складів, кнопка «Поділитися».

## Важливо
- ESPN API не має офіційної документації й може змінитися. Якщо логотипів чи таблиць немає, застосунок покаже помилку й працюватиме з рештою даних.
- Кредити Odds API: одне оновлення коштує приблизно по одному на кожен увімкнений турнір. Дані кешуються (коефіцієнти 3 години, ESPN 6, API-Football 6).
- Це аналітика, а не гарантія результату.

## Облік прогнозів
Вкладка «Статистика»: прогнози фіксуються автоматично до початку матчу, результати підтягуються з ESPN. Показує % вгаданих (1/X/2, точний рахунок, тотал 2,5, обидві заб’ють), точність за рівнем впевненості й турнірами, порівняння «ви проти моделі», експорт/імпорт історії.

## Ринок, форма, нагадування
- Вкладка «⚡ Розбіжності» та блок «Модель проти ринку»: порівняння ймовірностей ринку зі статистичною моделлю.
- Форма: матчі ESPN за 8 тижнів із вагою за давністю, впливає на статистичну частину з вагою 35%; у картці показано останні 5.
- Нагадування: кнопка «У календар» у картці матчу та для всіх обраних (.ics зі сповіщенням за годину).

## Екрани
Нижня навігація: Матчі, Обрані, Статистика, Ще (налаштування, ключі, стан даних). Картка матчу відкривається окремою сторінкою; кнопка «Назад» або свайп закриває її.
